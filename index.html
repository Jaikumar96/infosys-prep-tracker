🧠 Pattern Recognition Cheat Sheet

If the question says...Think of this pattern
"Find pair/triplet with sum X"Two Pointers (sorted) or HashMap
"Subarray with sum/product = K"Prefix Sum + HashMap or Sliding Window
"Maximum/Minimum subarray"Kadane's Algorithm
"Find in sorted array"Binary Search
"Intervals, scheduling, meetings"Sort by end time + Greedy
"Minimum cost/steps to reach"DP or BFS
"Count ways to do X"DP (usually 1D or 2D)
"Longest/Shortest subsequence"DP (LCS / LIS pattern)
"Connected components / islands"BFS or DFS
"Can partition into equal subsets"0/1 Knapsack DP
"String matching / edit / transform"2D DP (LCS / Edit Distance)
"Maximum profit with constraints"DP + Binary Search or Greedy
